Discovery verdict

The only third-party brand logo visibly rendered on the existing website is the DJI mark printed on the drone body in the Vente ("Pôle 01 — Commerce") service photograph — Pexels photo 9182739, referenced by src/lib/images.ts as serviceImages.vente.

An exhaustive search of the implementation (working tree, full git history, built single-file app, all content/data, all image/SVG references, public/, config, sibling repos) found no partner logo asset — not local, not code-generated, not a referenced remote logo URL. Every logo reference in the codebase is the FEL DRONE brand, which was not used here.

The mark therefore exists inside a licensed stock photograph — a small, tilted, photo-graded raster. No vector master, colour spec or clear-space definition exists in the project. DJI is a third-party registered trademark: this page documents presence only. A partner identity system cannot be mechanically derived from this source without official asset files and rights clearance. Confirmation required before Phase 2: is this mark the intended partner logo, or does the approved logo exist elsewhere?

03

Master

preserved source
Master status: NO vector/logo master exists in the project. The authority is the photographic mark itself — a raster element of the stock photo. There is no approved SVG, no colour specification, no grid/clear-space definition anywhere in the repository (verified across the full git history).
Consequence: "preserve the approved geometry" cannot be satisfied against a vector master because none exists. Any attempt to reproduce the mark as clean vector geometry would be a redraw — explicitly forbidden by the partner mission. This page therefore presents pixel-identical crops only.
